# 🌐 Human Rights Hub Web Application

Human Rights Hub သည် လူ့အခွင့်အရေးဆိုင်ရာ ဗဟုသုတများ၊ အစီရင်ခံစာများနှင့် သတင်းအချက်အလက်များကို အလွယ်တကူ လေ့လာဖတ်ရှုနိုင်ရန် ဖန်တီးထားသည့် Responsive Web Application တစ်ခု ဖြစ်ပါသည်။

---

## 🌟 Key Features (အဓိက ပါဝင်သော လုပ်ဆောင်ချက်များ)


- **Responsive Design:** မိုဘိုင်းဖုန်း၊ တက်ဘလက်နှင့် ကွန်ပျူတာ Screen အားလုံးတွင် ကြည့်ရှုရ အဆင်ပြေအောင် ပြုလုပ်ထားခြင်း
- **Information Hub:** လူ့အခွင့်အရေးဆိုင်ရာ ဆောင်းပါးများနှင့် အချက်အလက်များကို စနစ်တကျ ကဏ္ဍခွဲ၍ ဖော်ပြထားခြင်း
- **Interactive UI:** သန့်ရှင်းသပ်ရပ်ပြီး အသုံးပြုရ လွယ်ကူသော User Interface

## 🛠️ Tech Stack (အသုံးပြုထားသော နည်းပညာများ)

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling & Icons:** Font Awesome, Google Fonts
- **Database / Backend:** Firebase (Authentication / Firestore)
